# Developer command test script for Cloak of Darkness.
# Demonstrates the ">" developer-command prefix (see cli/src/scriptrunner.ts and
# engine/src/debug.ts) - used to set up scenarios that would be awkward to reach by
# playing normally: jumping straight to a room, and grabbing/dropping an item that
# was never carried.

Foyer of the Opera House

> teleport bar
Player teleported to location bar.

$ look
It is dark, you cannot see a thing.

> get hook
Item hook added to player inventory.

$ inventory
small brass hook

> drop hook
Item hook dropped in current location.

$ inventory
! small brass hook

> get hook

# A "---" line ends the current test and restarts a fresh game, so state from
# the section above (eg the hook we just got) doesn't leak into what follows.
--- restart test: confirm the previous section's state doesn't carry over

Foyer of the Opera House

$ inventory
! small brass hook

# "--- sandbox" restarts into an empty sandbox room, and "@item <id>" moves an
# item into it - so the hook can be examined on its own, with the cloak,
# message and other rooms all still present in the game but out of scope.
--- sandbox: test the hook in isolation
@item hook

$ examine small brass hook
screwed to the wall

# "@room <direction>:<id>" gives the sandbox room an exit in that direction and
# auto-creates the target as an empty room - so motion (walking, or pushing an
# object between rooms) can be tested without needing a full second room of the
# real game. Here it's just used to confirm walking works from the sandbox.
--- sandbox: test walking out of the sandbox room
@room north:sandbox_hall

$ go north
An empty room named "sandbox_hall"

# "solve" (see src/verbs/solve.yaml) calls createPlan to search - by simulating go/hang/
# examine commands against forked copies of the game state (see
# engine/src/commandplanner.ts), never the real one - for a route to the maximum score.
# Only the two actions that actually earn points are asserted (not the full command
# list createPlan happens to return), since the exact route found isn't part of the
# contract and shouldn't make this test brittle to unrelated search changes.
--- solve: createPlan finds a route to maximum score, without touching the real game
Foyer of the Opera House

$ solve
hang cloak on hook

examine message

# Confirm the search really was only ever simulated: still in the foyer, still wearing
# the cloak, ready to be played normally.
$ inventory
velvet cloak (wearing)

$ look
chandeliers
